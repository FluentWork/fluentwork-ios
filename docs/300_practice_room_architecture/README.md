## 项目背景

**FluentWork** 是面向全球协作程序员的职场英语情景演练 App。本架构设计聚焦核心功能 **Practice Room**（说的房间）——让用户通过真实工作素材驱动的 AI 语音对话进行实战演练。

### 产品定位

> 把你的工作日常变成英语练习——以真实工作场景为料、以口语演练为核心的个性化职场英语训练引擎。

### 核心差异化

与豆包、ChatGPT 等通用 AI 的本质区别：
- **不是聊天工具，是训练系统**：带间隔重复和刻意练习的完整训练营
- **个人语料库**：话术块三元组资产沉淀，练得越久迁移成本越高
- **素材驱动**：练习内容来自用户真实工作素材
- **结构化反馈**：三层评价 + 双栏对照，不是简单纠错
- **实战出口**：话题建议 → 真人聊天，闭环回流

## 核心功能

### 完整流水线

```
用户投喂素材（工作文档/会议记录）
    ↓
说（实战演练）─────────────┐
    ↓                      │ Practice Room
读（自我输出镜像）         │ 本架构范围
    ↓                      │
炼化（话术块萃取）─────────┘
    ↓
提取训练（闪测）
    ↓
语料库（资产沉淀）
    ↓
话题建议（真人实战）
```

| 功能 | 关键指标 | 技术挑战 |
|------|----------|----------|
| **实时语音对话** | 首响 P90 ≤ 1.5s | WebSocket duplex、流式处理 |
| **素材驱动对话** | ≥60% AI 话轮引用素材 | Prompt 构建、引用率监控 |

| **话术块炼化** | 3-5 个话术块 | 从卡壳点提炼三元组 |

## 设计原则

### 第一性原理

> 口语产出是实时过程，必须在数百毫秒内完成。大脑有两条路径：
> - **路径 A（提取）**: 现成表达整体调出，流利不卡
> - **路径 B（组装）**: 现场用规则组装，必然卡顿
>
> 用户问题本质是路径 A 库存太少，路径 B 占主导。

**四条产品级结论**:
1. 训练单位必须是话术块（chunk），不是单词
2. 主动召回训练，识别性知识不能自动转化为产出性知识
3. 素材相关性决定动机和留存
4. 即时强化的时效性决定习得效率

### 六大架构原则

1. **对准实时口语**: 首响延迟是生死线，延迟即体验
2. **用户素材驱动**: 真实工作素材贯穿对话、评价、炼化
3. **自输出镜像**: 让用户"看见"自己说的英文
4. **干预分层**: 对话流内只有卡壳救援，纠错后置到回顾
5. **Actor-first 并发**: 编译时并发安全，无 data race
6. **可观测性**: 全链路埋点，关键指标实时监控

## 关键技术挑战

### 1. 延迟优化（首响 ≤ 1.5s）

**挑战**: 首响延迟包含 WebSocket 连接、ASR 启动、LLM 首 token、TTS 首音频块

**策略**:
- 预连接：进入房间前预建 WebSocket
- 流式处理：ASR/LLM/TTS 全流式，不等完整结果
- 并行优化：命中检测并行于 TTS
- 降级方案：延迟超限降级为分段 TTS

### 2. 即时反馈误命中防御

**挑战**: 用户说了错的话却被正强化（信任崩塌）

**策略**:
- 阈值保守化：只有高置信命中才出徽章
- 语义判定：基于语义等价而非字面匹配
- 误命中率监控：上线前必测
- 远程开关：可远程关闭即时反馈

### 3. 卡壳救援依赖风险

**挑战**: 梯子给得太早，用户会等梯子不主动尝试

**策略**:
- 3秒阈值：给用户足够思考时间
- 逐层升级：不跳层，先给轻量提示
- 救援率监控：救援率过高 → 调整场景难度
- 不记入失败：救援过的话术块照常进入炼化

### 4. 素材引用率保障

**挑战**: AI 对话必须 ≥60% 引用素材内容

**策略**:
- Prompt 强制注入：素材提炼结果作为 System Prompt
- 话轮检测：每轮 AI 回复检测素材引用
- 引用率埋点：实时监控，低于阈值告警
- 素材重激活：连续未引用时 AI 主动提及

## 成功标准

### 技术指标

✅ 首响延迟 P90 ≤ 1.5s  
✅ 转录延迟 ≤ 1s  
✅ 命中检测延迟 ≤ 500ms（不阻塞）  
✅ 卡壳救援触发 ≤ 3s  
✅ 评价生成 ≤ 15s  
✅ 素材引用率 ≥ 60%  
✅ 核心链路可用性 ≥ 99.5%

### 业务指标

- **首次开口率**: 进入房间 → 说出第一句话（漏斗首环）
- **周完整流水线完成率**: 周完成"说 → 回顾 → 入库"≥1次（北极星指标）
- **话术块命中率**: 已入库话术块在对话中被用上的比例
- **卡壳救援触发率**: 有效救援占总对话的比例
- **卡壳救援有效率**: 救援后用户继续说话的比例

### 质量标准

- 稳定性：核心功能无 P0 Bug
- 可测试性：单元测试覆盖率 ≥ 70%，关键路径 ≥ 90%
- 可观测性：全链路埋点，关键指标可视化
- 可维护性：模块解耦，依赖注入，文档完整

## 风险管理

### GO/NO-GO 决策点

**Week 1-2 压测门槛**:
- 首响延迟 P90 必须 ≤ 1.5s
- 若不达标，启动降级方案并重估整体排期

### 主要技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 首响延迟超 1.5s | 产品生死线 | W1-W2 压测，不达标重估 |
| 即时反馈误命中 | 错误正强化 | 阈值保守化 + 误命中率测试 |
| 卡壳救援制造依赖 | 用户不主动尝试 | 3秒阈值 + 救援率监控 |
| 素材引用率不达标 | 与通用 AI 无差异 | Prompt 强制注入 + 实时监控 |
| WebSocket 不稳定 | 对话中断 | 自动重连 + 断线续传 |
