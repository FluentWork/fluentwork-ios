## 0. 这张图是怎么来的（先读这一节）

本机没有在跑后端，所以截图走 `FW_SCREEN=review`（`DebugScreenPreview`）：

- **回顾页这一段换的不是数据面，而是直接派一条「轮询回来了」**（`.review(.applyPoll(...))`）。
  它的数据面是 `SpeechSessionClientProtocol` —— 房间那个大协议，为截图替身它，换来的是
  「截图能证明轮询路径」的错觉。**轮询本身有中间件判据管着**，这里要看的是产出到手之后的形态。
- 另外：`.appear` 触发的轮询在本机必然失败（`.loadFailed`，**不重试**），会把相位从 ready
  打成 failed。所以摆位那一步在失败落地之后**把样例产出再种一次** —— 否则截到的是「暂不可用」。

⇒ 这张图**证明不了**「回顾真的拉到了」。它能证明的是：产出到手之后，这一屏按稿子的顺序画出来了。

## 2. 我单方面做的决定（稿子没写，请你确认或推翻）

1. **计数写「屏幕上真有的条数」，不读服务端的 `overview.issue_count`**。两者不一致时
   （服务端报 9 条、`review.issues` 只给 2 条），显示 2 —— 因为「查看全部 N 条」是这一屏
   唯一能兑现的承诺，报 9 却只列 2 条，学员会去找那 7 条不存在的。
2. **「+N 新增话术块」是产出，「M 个待入库」是进度**：点完「全部入库」之后前者不变、后者归零。
3. **「回合」= 学员自己说了几轮**（转录里 `speaker == "user"` 的条数），不是转录总行数。
4. **时长下限 1 分钟**：说了 20 秒也发生过，写「0 分钟」等于说没练。
5. **首屏只给 1 条对照 ＋ 1 个问题 ＋ 1 条建议**（稿子的阅读顺序纪律），其余收进「查看全部」——
   **原地展开**，不跳页。
6. **双栏做成上下两段，不是左右并排**。稿子写「窄屏下双栏各约 152pt 文本宽，长句会折到 3 行」，
   而这一屏在 393pt 宽下两栏各 152pt 意味着英文句子要折 3 行、中文标签也要缩到很小；
   上下两段的并置感靠**同一张卡里紧挨着**给出，差异词的下划线让「哪里不同」一眼可见。
   **要你定的是这一条**：如果你要严格的左右并排，我把卡片切成两栏再走一遍。
7. **「再来一轮」回到创建练习弹层**（屏 11），不直接进房间 —— 那一屏存在的理由就是
   「今天练什么」由学员选，绕开它等于把上次的选择当成这次的选择。
8. **页头「回顾」＋ 右上 ✕ 收到这一屏自己**。原来 ✕ 是宿主盖在内容上的悬浮件，
   **它压住了总结条第一行**（截图抓到，把「12 分钟」盖没了）。稿子的左上角本来就写着「回顾」，
   所以页头归这一屏，✕ 跟它同一行。

## 3. 四种状态各一遍

| 状态 | 怎么造 | 该看到 | ✅/❌ |
|---|---|---|---|
| 生成中 | 进页面后 3 秒内 | 转录/总结条已出现，评价区是**闪光骨架块**＋「正在分析你的表达…」 | |
| 就绪 | 产出到手 | 上面那一整屏 | |
| 失败 | 断网后进 | 「回顾暂不可用」＋一句原因＋「重试」；**不留空白页** | |
| 局部失败 | 入库请求失败 | 炼化区里出现原因，**其余部分照旧可读** | |
| 全入库 | 点「全部入库」 | 卡片带「已入库」标记、改/丢两个入口撤掉、「待入库」这一项消失 | |
| 丢弃后撤回 | 丢一张再点「撤回」 | 卡回到列表，顺序不乱 | |

## 4. 没做的（都不是漏，是记着的）

| 项 | 为什么不做 |
|---|---|
| **顶部日期（「9月26日」）** | **产出里没有会话日期**。要 `GET /sessions/:id` 的 `started_at`，或后端在 review 里补一个字段 —— ④ 类缺口，跨仓。 |
| **「原音」「示范」两个按钮** | 稿子画在对照卡上，但它**自己就把「整段听原音」标成「未解决」**（需要一段的起止时间戳，PRD §9.1 口径归档）；「示范」要一条「把任意句子读出来」的 TTS 入口，iOS 侧今天没有。 |
| **「可回听」** | 转录按话轮展示有了，「回听」要音频。 |
| **段落层（屏 14）** | 稿子：一口气说满 3 句以上时页面顶端多一层「这一段整体」的对照。那是独立一票。 |
| **G4 注册时机** | 游客点「全部入库」→ 页内底部轻量面板「登录后，这些表达才真正属于你」。**要一条登录链路**：今天 iOS 只有游客身份与 `mergeGuestAccount`，没有任何登录入口。先做一个面板而没有登录可走，等于造一个点了没反应的入口 —— 记为独立票。 |
