## 4. 破坏性操作可撤回（D2 的丢弃正是这一类）

- [ ] 丢弃一张炼化卡 → 它从「Refine Cards」段消失、出现在**「已丢弃」段**。
- [ ] 点「撤回」→ 它回到原段，**位置也对**（不是跑到最后）。
- [ ] 丢弃一张**改过**的卡再撤回 → 改动还在（`已修改` 标记仍在）。
- [ ] 忽略一张话题卡 → 它离开列表；「今天已聊过 N 张」的 N **不变**。
- [ ] 打卡后再刷新列表 → 已打卡的卡**还在**（带「今天聊过」标记），N +1。
