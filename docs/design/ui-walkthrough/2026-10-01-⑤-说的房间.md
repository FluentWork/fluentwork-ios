## 1. 单元 A 落在判据上的规则

| 规则 | 它挡的是什么 |
|---|---|
| **卡壳点按说话人往回找**，不取 `timeline.last` | 静默到点时时间线尾部往往已经多了一条 AI 的提示占位 —— 取 last 会把「卡壳点」打在刚递出去的提示上 |
| **卡壳点是一条标记，不是删除** | 稿子的硬约束：那句截断的话保留在时间线上、照常进 D1 炼化候选（「卡壳点正是最该练的东西」） |
| **被打断由 `aiSpeaking → recording` 这对相位判定** | 只有这一种成因是 barge-in。其它转移（处理中→录音、等待中→录音）**不误标** |
| **浮层只在录音态、且那句话还没进气泡时有内容** | 「禁止双重展示」的两半，见 §4 第 1 条 |
| **「用上 N 个」在 0 时不显示** | 写「用上 0 个」是在报告一件没发生的事 |
| **救援三句只在就绪时出现**（`isRescueHintDue && awaitsUserTurn`） | AI 正在说的时候静默不该递提示，也不该写「已经 3 秒没有听到你」 |
| **两个标记文案两两不同** | 一个灰签写着「卡壳点」、另一个也写着它 —— 稿子上看不出来，真机上要用眼睛撞见 |
| **录音态的状态行是稿子原话**「轮到你了 · 我正在听」 | 其余状态沿用既有那套中文，不另写一句同义的 |

## 2. 我单方面做的决定（稿子没写，请你确认或推翻）

1. **「第 N 轮」＝ 已说完的轮数 ＋ 1**（正在进行的这一轮）。两种读法都说得通，我取前者，
   因为稿子 屏 02「第 3 轮」底下正好三条气泡。**这一条最想让你在真机上确认。**
2. **认不出的场景名用原值**（`allhands` 就写 `allhands`），不折成某个已知场景。
3. **场景名复用屏 08 那张词表**（`CorpusSceneFilter`，已对着契约逐字核过）。
4. **「重播 / 可回听」先不画**：稿子把「AI 重播」「你说 · 可回听」画在气泡的 meta 行上，
   但那要音频通道（重播要时间段戳，回听要录音）。画一个点了没反应的按钮比不画更糟，
   所以只留「AI」「你说」两个说话人标签。
5. **录音态的按钮文案沿用既有的「说完了」**（稿子的 `[fw-mic rec]` 没写按钮上的字，
   只给了状态行）。既有的那套中文在仓里已有判据与走查，不另起一套。
6. **练完自动落到回顾页**。删除底栏之后，「查看回顾」这个入口没有了 —— 而稿子 屏 04 自称
   「首次体验的 wow moment 承载页」，它本来就该紧跟一次练习出现。所以改成
   **会话结束（`.ended`）⇒ 回顾自己出现**，而不是在房间里再放一个按钮。
   **要你确认的是这一条**：它把「看回顾」从一次点击变成了自动转场。

## 3. 单元 B 抓到的三件事

1. **宿主盖在房间上的悬浮 ✕ 压住了新的顶部栏**（截图里它正好压住返回键的位置）。
   与回顾页同一处毛病：返回键收进这一屏自己，悬浮件撤掉。
2. **同一句话在浮层与气泡里各出现一次** —— 正是稿子第一条易错点。原因是
   `serverASRReceived` **一次动作里同时**写 `liveTranscript` 与气泡，而它到达时相位未必翻过录音态。
   于是规则补了第二半：「那句话已经进了气泡，浮层就撤」。判据 `那句话已经进了气泡时浮层要撤`。
3. （核对，不是 bug）顶部那枚绿色徽章是**既有的浮动徽章层**，它与气泡上的角标是同一件事的
   两个阶段 —— 稿子写着「徽章的弹出位置、200ms 弹性、**1.5 秒停留**、**收起为角标**」。
   截图正好落在弹出窗口内。时限的偏差见 §4 第 2 条。
4. **自造的「结束练习」底栏**（你点出来的）。全仓对着稿子搜过：**`结束练习`／`结束这次`／
   `结束会话` 零命中**，只有 4 处 `结束本轮`（都在 屏 02/03 的顶部栏里）。所以整条底栏
   删掉了，**连同它的 `.ended` 分支**（「本轮要点 ＋ 查看回顾 ＋ 返回工作台」）——
   那三个东西也都不在稿子里。两个连带处理：
   - **一次练习不能因为一下误触就没了**：那条保护原来挂在红按钮上，现在跟着**返回键**走
     （会话在跑 → 先问「结束这次练习？」，没在跑 → 直接退出）；
   - **「查看回顾」的入口改成自动转场**（见 §2 决定 6）。

## 4. 没做的 / 偏差（逐条写了理由）

| 项 | 情况 |
|---|---|
| **浮层那一句实时转写** | 规则在了，但**今天它看不到内容**：`liveTranscript` 唯一的写入者是服务端转写（`serverASRReceived`），而它一到就把同一句写进气泡、浮层随即撤掉。稿子的「浮层实时滚动」要的是**客户端侧的实时 ASR**，那条链路还没接（`ClientASRTranscriber` 是一份没接线的文档）。 |
| **徽章停留 1.5 秒 ＋ 收起为角标** | **偏差**：仓里是 `visibleWindowSeconds = 4.0`（`BadgeFeedbackFeature.swift:91`），稿子写 1.5 秒；而且「200ms 弹性 ＋ 收起为角标」这套动效还没做（气泡上那枚角标是常显的，不是收起来的）。这是一条**独立的动效票**，不改它的一半。 |
| **目标胶囊**（目标句 ＋ 素材摘要） | **数据不在**：`CreateSessionResponse` 只回 `session_id/wss_url/ticket/scene_type/status`（契约 `openapi-v1.yaml:1290-1300`）。跨仓。 |
| **三层梯子 ＋ 三点指示器**（屏 03 的核心） | **后端与协议都没有生产者**：全仓搜 `ladder` 零命中；WSS 控制帧契约里没有救援帧。这条链路还不存在，要单独开跨仓票。 |
| **重播 / 回听 / 梯子的 TTS 朗读** | 音频通道。 |
| **波纹随真实音量起伏** | 今天没有音量信号暴露到视图层。**不做假的波纹**。 |
| **三条提示音** | 与设置项绑定，而设置页是屏 12。 |
