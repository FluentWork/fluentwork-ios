## 0. 这一票拆成了两个单元（先看这里）

这一屏是稿子里**最重的一屏**（全屏沉浸页、设计权重最高），而且它的稿子里有三层东西：
版式、语音状态机、救援梯子。一次做完会让「哪一层没做」说不清，所以拆成：

| 单元 | 内容 | 状态 |
|---|---|---|
| **A. 状态层与投影** | 卡壳点、被打断、第几轮/场景/时长、**禁止双重展示**、救援三句 | ✅ **已完成**（判据 16 条，变异 **10/10**） |
| **B. 视图重排** | 顶部栏、时间线气泡、实时转录浮层、72pt 说话键三态、救援块、截图 | ⬜ 下一轮 |

**为什么先做 A**：稿子把「三条易错点」写成了这一页的核心设计物，而它们**全是规则**——
「禁止双重展示」「被打断要说清」「不记入失败」。规则住错了地方（写进视图）就没人守得住：
`liveTranscript` 在录音结束后**仍然留着**那句话，浮层只要无条件读它，屏幕上就会同时出现两份同样的字。

## 1. 单元 A 已经落在判据上的规则

| 规则 | 它挡的是什么 |
|---|---|
| **卡壳点按说话人往回找**，不取 `timeline.last` | 静默到点时时间线尾部往往已经多了一条 AI 的提示占位 —— 取 last 会把「卡壳点」打在刚递出去的提示上 |
| **卡壳点是一条标记，不是删除** | 稿子的硬约束：那句截断的话保留在时间线上、照常进 D1 炼化候选（「卡壳点正是最该练的东西」） |
| **被打断由 `aiSpeaking → recording` 这对相位判定** | 只有这一种成因是 barge-in。其它转移（处理中→录音、等待中→录音）**不误标** |
| **浮层只在录音态有内容** | 「禁止双重展示」：话音落下后同一句话只留在气泡里 |
| **「用上 N 个」在 0 时不显示** | 写「用上 0 个」是在报告一件没发生的事 |
| **救援三句只在就绪时出现**（`isRescueHintDue && awaitsUserTurn`） | AI 正在说的时候静默不该递提示，也不该写「已经 3 秒没有听到你」 |
| **两个标记文案两两不同** | 一个灰签写着「卡壳点」、另一个也写着它 —— 稿子上看不出来，真机上要用眼睛撞见 |

## 2. 我单方面做的决定（稿子没写，请你确认或推翻）

1. **「第 N 轮」＝ 已说完的轮数 ＋ 1**（正在进行的这一轮）。两种读法都说得通
   （「你在第几轮」/「你说完了几轮」），我取前者，因为稿子 屏 02「第 3 轮」底下正好三条气泡。
   **这一条最想让你在真机上确认。**
2. **认不出的场景名用原值**（`allhands` 就写 `allhands`），不折成某个已知场景 ——
   与状态灯同一条纪律：宁可显示得笨，也不要显示一个确定但错的名字。
3. **场景名复用屏 08 那张词表**（`CorpusSceneFilter`）：它已经对着契约的 enum 逐字核过，
   房间再抄一份就有了两个会漂的源。

## 3. 没做的（逐条写了理由，都不是漏）

| 项 | 为什么不做 |
|---|---|
| **目标胶囊**（「用上 2 个」/目标句/素材摘要） | **数据不在**：`POST /sessions` 的 `CreateSessionResponse` 只有 `session_id/wss_url/ticket/scene_type/status`（契约 `openapi-v1.yaml:1290-1300`），既不回**目标句**也不回**素材摘要**。做一个只剩「用上 N 个」的胶囊，等于把「让学员随时知道这局在练什么」那个理由抽掉。要把这两样加进创建回包或单开一个上下文端点 —— 跨仓。 |
| **三层梯子 ＋ 气泡下方的三点指示器**（屏 03 的核心） | **后端与协议都没有生产者**：全仓搜 `ladder` 零命中；WSS 控制帧契约里没有救援帧；后端只有 drill 那边一个只读的 `CountRescuesByPath`。**这不是「客户端没做」，是这条链路还不存在** —— 要后端出三层内容 ＋ 协议出层号，客户端才有东西可画。 |
| **重播 / 回听 / 梯子的 TTS 朗读** | 音频通道：重播要那一段的起止时间戳（稿子自己把「整段听原音」标成未解决），朗读要一条「把任意句子读出来」的入口。 |
| **波纹随真实音量起伏** | 今天没有音量信号暴露到视图层。**不做假的波纹** —— 一个与声音无关的动画在教人「按得越大声波纹越大」。 |
| **三条提示音**（处理中呼吸音 / 断线提示音 / 恢复时 AI 带过） | 与设置项绑定（「均可在设置单独关闭」），而设置页是屏 12。 |
