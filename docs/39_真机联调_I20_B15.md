## 今晚 iOS 侧

1. 查 Mac IP：`ipconfig getifaddr en0`（空则 `en1`）。这是 `$HOST`，**不是**手机 IP。
2. `$HOST` 不是 `192.168.2.15` 时，Xcode Scheme → Run → Environment Variables：

   ```text
   LOCAL_HOST = 192.168.x.x
   ```

   正好是 `192.168.2.15` 时可省略（`AppEnvironment.local` 默认）。
3. 装 `d8a9643` 到真机，允许本地网络权限。
4. 说的房间：**开口 → 松手**（场景 1），再 **按住约 60s 不松手**（场景 2，abort）。对照 backend `docs/41` §4。
