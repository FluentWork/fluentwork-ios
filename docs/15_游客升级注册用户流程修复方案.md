# 游客升级注册用户流程修复方案

**问题编号**: I15  
**优先级**: P0  
**日期**: 2026-09-01

---

## 一、产品需求（PRD G4 模块）

### 核心用户体验
1. **免注册启动**：App 首次启动自动获取游客 token，直接进入演示闭环
2. **延迟注册**：用户在首次"保存语料"时才触发注册引导
3. **无损归并**：注册后，游客期间的练习数据自动归并到注册账号，**不允许丢数据**

### 产品原则
> "不允许被迫提前登录破坏主路径"  
> "游客期练习数据幂等归并到账号"

## 二、后端 API 实现现状（✅ 完整支持）

### 1. 游客 Token 自动签发
```http
POST /auth/guest
Content-Type: application/json

{
  "device_id": "device-uuid-xxx"
}

Response 200:
{
  "user_id": "guest-xxxx",
  "is_guest": true,
  "status": "active",
  "access_token": "eyJ...",
  "refresh_token": "...",
  "token_type": "Bearer",
  "expires_in": 3600
}
```

**幂等性保证**：
- 同一 `device_id` 多次调用返回同一游客账号
- 如果该设备已归并，直接返回注册用户的 token

### 2. 数据归并 API
```http
POST /account/merge
Authorization: Bearer <注册用户的 access_token>
Content-Type: application/json

{
  "device_id": "device-uuid-xxx"
}

Response 200:
{
  "user_id": "user-real-42",
  "is_guest": false,
  "merged_from_user_id": "guest-xxxx",  // 被归并的游客 ID
  "already_merged": false
}
```

**归并机制**：
- 跨模块链式调用：`account` → `corpus` → `content` → `session`
- 原子性操作：所有游客数据的 `user_id` 字段统一更新为注册用户 ID
- 幂等性：重复调用返回 `already_merged: true`，不报错

### 3. 支持的归并数据范围
- ✅ **语料库** (`corpus.phrase_blocks`)
- ✅ **练习记录** (`sessions.practice_sessions` + `utterances`)
- ✅ **每日一读** (`content.daily_reads`)
- ✅ **素材** (`account.materials`)

## 三、iOS 客户端当前问题（❌ 未实现归并流程）

### 问题 1: Bootstrap 只获取 token，不更新 AuthState
**文件**: `AppBootstrapMiddleware.swift`

```swift
// 当前实现：只获取 token 存储到 keychain
private func ensureGuestToken() async throws {
    if let existingToken = try tokenStore.accessToken(), !existingToken.isEmpty {
        return
    }
    let deviceID = try tokenStore.deviceID()
    let tokenResponse = try await sessionAPI.issueGuest(deviceID: deviceID)
    try tokenStore.save(tokens: tokenResponse, deviceID: deviceID)
    // ❌ 没有 dispatch .auth(.signedInAsGuest) action
}
```

**影响**：
- `AuthState` 仍然是 `.notAuthenticated`
- UI 显示"未登录"状态
- 后续 API 调用虽然有 token，但状态机不正确

### 问题 2: 缺少 Promote 流程
**当前流程**：
```
用户点注册 → 邮箱验证 → 获取新 token → ❌ 游客数据丢失
```

**应有流程**：
```
用户点注册 → 邮箱验证 → 调用 /account/merge → 更新 token → 更新 AuthState
```

### 问题 3: 缺少 AuthAction 定义
**文件**: `AuthFeature.swift`

```swift

  case signedInAsGuest(userID: String, deviceID: String)      // ✅ 已定义
  case mergedIntoRegistered(userID: String, deviceID: String) // ✅ 已定义
  case signedOut                                               // ✅ 已定义

```

**状态机**：
```swift

  case notAuthenticated

```

✅ **已定义但未使用**：`signedInAsGuest` 和 `mergedIntoRegistered` action 已存在，但没有在 bootstrap 和注册流程中 dispatch。

## 四、修复方案

### 修复 1: Bootstrap 完成后 dispatch guest auth action

**文件**: `AppBootstrapMiddleware.swift`

```swift
public static func make(container: Container? = nil) -> Middleware<AppState, AppAction> {
    let resolvedContainer = container ?? Container.shared

    return { store, action, next in
        guard case .lifecycle(.appLaunched) = action else {
            return next(action)
        }
        guard store.state.bootstrapStatus != .loading else {
            return next(action)
        }

        let bootstrapClient = resolvedContainer.bootstrapClient()
        let base = next(action)

        return .merge(
            base,
            .task(id: AppTaskID.bootstrap) {
                do {
                    let result = try await bootstrapClient.loadBootstrap()
                    guard !Task.isCancelled else { return nil }
                    
                    // ✅ 返回 bootstrap + auth 信息
                    return .lifecycle(.bootstrapSucceeded(
                        snapshot: result.snapshot,
                        authInfo: result.authInfo
                    ))
                } catch is CancellationError {
                    return nil
                } catch {
                    guard !Task.isCancelled else { return nil }
                    return .lifecycle(.bootstrapFailed(appBootstrapErrorMessage(error)))
                }
            }
        )
    }
}
```

### 修复 2: BootstrapClient 返回认证信息

**文件**: `AppDependencies.swift`

```swift
// 新增：Bootstrap 结果携带认证信息
public struct BootstrapResult: Equatable, Sendable {
    public var snapshot: BootstrapSnapshot
    public var authInfo: AuthInfo?
    
    public init(snapshot: BootstrapSnapshot, authInfo: AuthInfo? = nil) {
        self.snapshot = snapshot
        self.authInfo = authInfo
    }
}

public struct AuthInfo: Equatable, Sendable {
    public var userID: String
    public var isGuest: Bool
    public var deviceID: String
    
    public init(userID: String, isGuest: Bool, deviceID: String) {
        self.userID = userID
        self.isGuest = isGuest
        self.deviceID = deviceID
    }
}

// 修改协议
public protocol BootstrapClientProtocol: Sendable {
    func loadBootstrap() async throws -> BootstrapResult
}

// 修改实现
public struct ResolverBackedBootstrapClient: BootstrapClientProtocol {
    // ... existing properties ...
    
    public func loadBootstrap() async throws -> BootstrapResult {
        // Ensure guest token and capture auth info
        let authInfo = try await ensureGuestToken()
        
        _ = await resolver.refresh()
        let remote = resolver.snapshot(for: AppFeatureFlag.allCases)
        let snapshot = BootstrapSnapshot(
            featureFlags: FeatureFlagSnapshotMapper.map(remote),
            preferredSurface: preferredSurfaceProvider()
        )
        
        return BootstrapResult(snapshot: snapshot, authInfo: authInfo)
    }
    
    /// Ensures a valid guest token exists and returns auth info.
    private func ensureGuestToken() async throws -> AuthInfo {
        let deviceID = try tokenStore.deviceID()
        
        // Check if we already have a valid access token
        if let existingToken = try tokenStore.accessToken(), !existingToken.isEmpty {
            // Parse existing token to get user info
            if let userID = try? tokenStore.userID() {
                let isGuest = try? tokenStore.isGuest() ?? true
                return AuthInfo(userID: userID, isGuest: isGuest, deviceID: deviceID)
            }
        }
        
        // No token exists, issue a new guest token
        let tokenResponse = try await sessionAPI.issueGuest(deviceID: deviceID)
        try tokenStore.save(tokens: tokenResponse, deviceID: deviceID)
        
        return AuthInfo(
            userID: tokenResponse.userID,
            isGuest: tokenResponse.isGuest,
            deviceID: deviceID
        )
    }
}
```

### 修复 4: 注册流程调用 merge API

**文件**: 创建新的 `AuthMiddleware.swift`

```swift
import TGReduxKit
import Foundation

public enum AuthMiddleware {
    /// Handles post-registration guest data merge.
    public static func make(container: Container? = nil) -> Middleware<AppState, AppAction> {
        let resolvedContainer = container ?? Container.shared
        
        return { store, action, next in
            let base = next(action)
            
            // 监听注册成功的 action
            guard case let .auth(.registeredSuccessfully(userID, token)) = action else {
                return base
            }
            
            let accountAPI = resolvedContainer.accountAPIClient()
            let tokenStore = resolvedContainer.authTokenStore()
            
            return .merge(
                base,
                .task {
                    do {
                        // 1. 保存新 token
                        try tokenStore.saveAccessToken(token)
                        
                        // 2. 获取 device ID
                        let deviceID = try tokenStore.deviceID()
                        
                        // 3. 调用 merge API
                        let mergeResult = try await accountAPI.merge(deviceID: deviceID)
                        
                        // 4. 更新状态
                        return .auth(.mergedIntoRegistered(
                            userID: mergeResult.userID,
                            deviceID: deviceID
                        ))
                    } catch {
                        // Merge 失败记录日志但不阻断用户
                        print("⚠️ Guest data merge failed: \(error)")
                        return nil
                    }
                }
            )
        }
    }
}
```

### 修复 5: TokenStore 增加辅助方法

**文件**: `AuthTokenStore.swift`

```swift
public protocol AuthTokenStoreProtocol: Sendable {
    // ... existing methods ...
    
    /// Extracts user ID from stored access token (optional, for convenience)
    func userID() throws -> String?
    
    /// Checks if current user is a guest (optional, for convenience)
    func isGuest() throws -> Bool
}

extension KeychainAuthTokenStore {
    public func userID() throws -> String? {
        guard let token = try accessToken() else { return nil }
        // Parse JWT payload to extract user_id
        // 简单实现：split by ".", base64 decode middle part
        let parts = token.split(separator: ".")
        guard parts.count == 3,
              let payloadData = Data(base64Encoded: String(parts[1])),
              let payload = try? JSONSerialization.jsonObject(with: payloadData) as? [String: Any],
              let sub = payload["sub"] as? String else {
            return nil
        }
        return sub
    }
    
    public func isGuest() throws -> Bool {
        guard let token = try accessToken() else { return true }
        let parts = token.split(separator: ".")
        guard parts.count == 3,
              let payloadData = Data(base64Encoded: String(parts[1])),
              let payload = try? JSONSerialization.jsonObject(with: payloadData) as? [String: Any],
              let isGuest = payload["is_guest"] as? Bool else {
            return true
        }
        return isGuest
    }
}
```

## 五、完整流程示意图

### 流程 A: 首次启动（游客）
```
App 启动
  → AppBootstrapMiddleware 触发
  → bootstrapClient.loadBootstrap()
      → ensureGuestToken() 
          → tokenStore 无 token
          → POST /auth/guest { device_id }
          → 保存 token 到 keychain
          → 返回 AuthInfo(guest-xxx, isGuest=true, device-yyy)
      → 加载 feature flags
      → 返回 BootstrapResult(snapshot, authInfo)
  → dispatch .lifecycle(.bootstrapSucceeded(snapshot, authInfo))
  → AppReducer 处理
      → 更新 bootstrapStatus = .ready
      → dispatch .auth(.signedInAsGuest(guest-xxx, device-yyy))
  → AuthFeature 更新
      → AuthState 变为 .guest(userID: guest-xxx, deviceID: device-yyy)
  ✅ UI 显示"游客模式"，用户可以体验完整功能
```

### 流程 B: 游客注册升级
```
用户点击"保存语料" 
  → 触发注册引导弹窗
  → 用户输入邮箱、验证码
  → dispatch .auth(.register(email, code))
  → 注册成功，后端返回 { user_id, access_token, is_guest=false }
  → dispatch .auth(.registeredSuccessfully(user-42, new_token))
  → AuthMiddleware 捕获
      → tokenStore.saveAccessToken(new_token)
      → deviceID = tokenStore.deviceID()
      → POST /account/merge { device_id }
      → 后端执行链式数据归并
      → 返回 { user_id: user-42, merged_from_user_id: guest-xxx }
      → dispatch .auth(.mergedIntoRegistered(user-42, device-yyy))
  → AuthFeature 更新
      → AuthState 变为 .registered(userID: user-42)
  ✅ 游客数据无损归并，用户继续使用
```

### 流程 C: 已注册用户再次启动
```
App 启动
  → bootstrapClient.loadBootstrap()
      → ensureGuestToken()
          → tokenStore 有 token
          → 解析 token 得到 userID + isGuest=false
          → 返回 AuthInfo(user-42, isGuest=false, device-yyy)
      → 加载 feature flags
      → 返回 BootstrapResult(snapshot, authInfo)
  → dispatch .lifecycle(.bootstrapSucceeded(snapshot, authInfo))
  → AppReducer 处理
      → dispatch .auth(.mergedIntoRegistered(user-42, device-yyy))
  → AuthFeature 更新
      → AuthState 变为 .registered(userID: user-42)
  ✅ 直接恢复注册用户状态
```

## 八、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| Token 解析失败 | 无法提取 user_id | 容错处理：解析失败则保持 `.notAuthenticated`，下次请求时后端重新签发 |
| Merge API 失败 | 游客数据丢失 | 记录日志但不阻断用户；后台异步重试；提供"恢复数据"入口 |
| 并发注册 | 多个 guest 同时升级到同一账号 | 后端 merge 接口已幂等；客户端加锁防并发 |
| 老版本兼容 | 老用户升级后数据丢失 | 发版前强制所有游客完成归并；提供数据恢复工具 |
